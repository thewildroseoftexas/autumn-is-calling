# Autumn is Calling

First interactive prototype of a layered autumn woodland geocaching mystery.

## Upload to GitHub Pages
1. Create a new public GitHub repository, e.g. `autumn-is-calling`.
2. Upload `index.html`, `autumn-forest.png`, and `.nojekyll` **to the repository root**.
3. Open Settings → Pages → Build and deployment → Deploy from a branch, `main`, `/ (root)` → Save.
4. Visit `https://YOUR-USERNAME.github.io/autumn-is-calling/` after deployment.

## What works now
- Click/tap six animals to trigger visual movement cues and synthesized sounds (sound must be turned on).
- A prototype click sequence unlocks a peel-away reveal of the placeholder second world.
- Reset, sound toggle, desktop and mobile responsive hotspots.

## To refine next
The animal movements are **prototype motion cues** over the static original illustration, not yet fully articulated animation of the actual painted animal bodies. Next stage: separate painted animal layers, character animation frames, more natural audio, and fully illustrated second world. The hidden sequence is currently visible in JavaScript source and must be replaced/secured before publishing as a live mystery cache. No final coordinates are included.
